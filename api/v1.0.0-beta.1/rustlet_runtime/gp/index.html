Allocation-free GlobalPlatform payload parsing and discovery encoding.

Readers return slices of the original input. They validate structure, not application identifiers, privileges, signatures or authorization. A successful parse never grants management authority. Writers borrow the caller’s output; an error may leave a partial object, which must not be published.

use rustlet_runtime::gp::{BerTlvReader, BerTlvWriter};
let mut bytes = [0; 16];
let len = {
    let mut writer = BerTlvWriter::new(&mut bytes);
    writer.primitive(&[0xC9], &[0x42]).unwrap();
    writer.len()
};
let mut reader = BerTlvReader::new(&bytes[..len]);
let item = reader.next_tlv().unwrap().unwrap();
assert_eq!(item.tag, 0xC9);
assert_eq!(item.value, &[0x42]);
reader.finish().unwrap();
