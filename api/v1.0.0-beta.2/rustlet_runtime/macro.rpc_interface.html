macro_rules! rpc_interface {
    ($vis:vis mod $name:ident, id = $id:expr, version = $version:literal {
        $(fn $method:ident($($arg:ident: $ty:ty),*) -> $ret:ty;)*
    }) => { ... };
}
Expand description

Declare a typed client, a server trait and its Postcard dispatcher.

Methods are numbered in declaration order. Changing their order or types requires a version change. Interface identifiers and versions are checked by the Rustlet dispatcher only. Service methods receive the kernel’s caller AID.

rustlet_runtime::rpc_interface! {
    pub mod counter, id = 42, version = 1 {
        fn add(value: u32) -> u32;
        fn value() -> u32;
    }
}
