6//! Application and Security Domain API for oXiDe SE Rustlets.
7//!
8//! # Start here
9//!
10//! | Task | API |
11//! | --- | --- |
12//! | Declare an application and its heap | `declare_rustlet!`, `Rustlet` |
13//! | Receive commands and produce responses | [`Apdu`], [`ApduStatus`] |
14//! | Decode installation parameters without allocation | [`gp::parse_install_for_install_ctx`] |
15//! | Encrypt, authenticate or derive keys | [`CryptoProvider`], [`Cipher`], [`Mac`], [`KeyAgreement`] |
16//! | Generate random data | [`RandomData`] |
17//! | Implement management and secure-channel policy | `RustletSecurityDomain`, `declare_security_domain!` |
18//! | Integrate an ABI or runtime | [`RustletCtx`], [`syscall_abi`], [`syscall`], `rt` |
19//!
20//! Application entry points require the **`runtime` feature** and the repository's
21//! nightly toolchain. Without it, shared types and parsers remain available for
22//! kernel and host tooling, but the allocator, entry macros and application
23//! traits are absent. Enable it when generating the complete reference.
24//!
25//! # Lifecycle and persistence
26//!
27//! A `no_std`, `no_main` Rustlet is packaged as an FAE and loaded into a running
28//! devkit. Pico 1 uses `thumbv6m-none-eabi`. The declaration macro requires
29//! `Default`, [`serde::Serialize`] and [`serde::Deserialize`], even with a custom
30//! installer. Installation creates the initial object; ordinary APDU calls
31//! reconstruct it and restore postcard state. On normal return the runtime
32//! serializes it, drops it, and the kernel scrubs its heap. Serialization errors
33//! abandon the invocation's staged state. The wrapper does **not** call the
34//! application's custom `load_state`/`save_state` overrides.
35//!
36//! Use serde attributes to choose persistent fields. Skipped fields are
37//! reconstructed for every ordinary invocation. Security Domains are different:
38//! their active secure-channel session may remain resident and should be excluded
39//! from serialization. [`persistence`] contains future streaming adapters, not
40//! the active postcard persistence implementation.
41//!
42//! # Memory and execution boundaries
43//!
44//! The shared context is [`APDU_SHARED_REGION_SIZE`] bytes: a control/state half
45//! and one APDU buffer reused for input and output. Payloads are limited to
46//! [`APDU_PAYLOAD_LENGTH_MAX`] bytes and serialized state to
47//! [`STATE_BUFFER_CAPACITY`] bytes. Borrow input only during its processing
48//! phase; [`Apdu::send_with`] generates output directly in shared storage.
49//! The macro's heap size and the FAE's stack requirement are independent.
50//! Neither Rust ownership nor successful QEMU execution establishes hardware
51//! isolation: Pico 1 has no MPU.
52//!
53//! Crypto services enter the kernel synchronously. Availability and random-source
54//! quality depend on the target. [`Cipher::update`] is unimplemented;
55//! [`Mac::update`] buffers up to 256 bytes. Prefer [`CryptoProvider::compute_mac`]
56//! for an already assembled message. Key wrappers are copyable values, not
57//! automatically zeroizing secret containers; avoid unnecessary copies and logs.
58//!
59//! # Reference scope
60//!
61//! The typed APIs above are the application interface. Public descriptor,
62//! syscall and `rt` items also serve separately compiled kernel/runtime glue;
63//! their visibility is not an invitation to bypass the typed API. Raw records
64//! carry no Rust lifetime proof. Read their contracts before integration.
65//! The kernel checks address ranges and authority at each service boundary.
66//! Host builds support parser and data-model tests; they do not emulate SVCs.
67//!
68//! Examples involving services must run inside a Rustlet. Pure parser examples
69//! are executable host doctests. Feature-gated entry examples are checked on
70//! the embedded target by the documentation validation script.

112/// Declares a Rustlet entry point and its private heap.
113///
114/// The generated entry point exposes only the lifecycle handlers consumed by the
115/// kernel. Persistent state is loaded and saved inside the Rustlet runtime
116/// around `install` and `process_apdu`.
117///
118/// Forms: `declare_rustlet!(T)`, `declare_rustlet!(T, heap_bytes)`, or
119/// `declare_rustlet!(T, heap_bytes, install_fn)`. The default heap is 768 bytes;
120/// it must fit the boxed application and its allocations. This does not size
121/// the stack. Use exactly one declaration per image.
122///
123/// `T` must implement [`Rustlet`], `Default`, [`serde::Serialize`] and
124/// [`serde::Deserialize`]. The custom installer has signature
125/// `fn(&mut RustletCtx) -> Result<T, ApduStatus>`; an error rejects installation.
126/// `Default` is still required to reconstruct subsequent calls. The generated
127/// postcard wrapper owns persistence; custom trait load/save overrides are not
128/// delegated to. No APDU/context borrow may escape a handler.
129macro_rules! declare_rustlet {
130    // --- Public API Overloads ---
131
132    // Default overload: use implicit install with a default heap size (768 bytes).
133    ($app_ty:ty) => {
134        $crate::declare_rustlet!(@implicit $app_ty, 768usize);
135    };
136
137    // Custom heap size overload with implicit install.
138    ($app_ty:ty, $heap_size:expr) => {
139        $crate::declare_rustlet!(@implicit $app_ty, $heap_size);
140    };
141
142    // Fully explicit overload: custom heap size and custom install function.
143    ($app_ty:ty, $heap_size:expr, $install_fn:path) => {
144        $crate::declare_rustlet!(@explicit $app_ty, $heap_size, $install_fn);
145    };
146
147    // --- Internal Implementation Detail: Implicit Installation ---
148    (@implicit $app_ty:ty, $heap_size:expr) => {
149        #[doc(hidden)]
150        /// Internal adapter for apps implementing Default for installation.
151        fn __oxide_se_implicit_install(ctx: &mut $crate::RustletCtx) -> core::result::Result<$app_ty, $crate::ApduStatus> {
152            <$app_ty as $crate::rt::DeclareAppWithoutInstallRequiresDefault>::implicit_install(
153                ctx,
154            )
155        }
156
157        $crate::declare_rustlet!(@explicit $app_ty, $heap_size, __oxide_se_implicit_install);
158    };
159
160    // --- Internal Implementation Detail: The Core Entry Point ---
161    (@explicit $app_ty:ty, $heap_size:expr, $install_fn:path) => {
162        extern crate alloc;
163
164        #[doc(hidden)]
165        static __OXIDE_SE_RUSTLET_HEAP_STORAGE: $crate::rt::RustletHeapStorage<{ $heap_size }> =
166            $crate::rt::RustletHeapStorage::new();
167
168        #[doc(hidden)]
169        /// Bridges the typed install function with the boxed trait object required by the runtime.
170        fn __oxide_se_install_adapter(
171            ctx: &mut $crate::RustletCtx,
172        ) -> core::result::Result<$crate::rt::RuntimeInstance, $crate::ApduStatus> {
173            let instance: $app_ty = $install_fn(ctx)?;
174            Ok($crate::rt::RuntimeInstance::App(alloc::boxed::Box::new(
175                $crate::rt::PersistentRustlet::new(instance),
176            )))
177        }
178
179        #[doc(hidden)]
180        fn __oxide_se_load_adapter(
181            _ctx: &mut $crate::RustletCtx,
182        ) -> core::result::Result<$crate::rt::RuntimeInstance, $crate::ApduStatus>
183        where
184            $app_ty: core::default::Default,
185        {
186            let instance = <$app_ty as core::default::Default>::default();
187            Ok($crate::rt::RuntimeInstance::App(alloc::boxed::Box::new(
188                $crate::rt::PersistentRustlet::new(instance),
189            )))
190        }
191
192        #[unsafe(no_mangle)]
193        #[doc(hidden)]
194        /// Low-level entry point called by the Kernel.
195        /// Initializes the allocator with the local storage and starts the Rustlet runtime.
196        /// # Safety
197        /// Called once by the kernel with this image's GP and exclusive memory
198        /// established; no previous runtime instance or handler may be active.
199        pub unsafe extern "C" fn start(buffer: *mut $crate::RustletCtx) -> ! {
200            // SAFETY: the kernel entry contract and private static heap establish
201            // the runtime startup obligations for this relocated image.
202            unsafe {
203                $crate::rt::start(
204                    __oxide_se_install_adapter,
205                    __oxide_se_load_adapter,
206                    buffer,
207                    __OXIDE_SE_RUSTLET_HEAP_STORAGE.as_mut_ptr(),
208                    $heap_size,
209                )
210            }
211        }
212    };
213}

226/// Declares a Rustlet that can also act as a user-land Security Domain.
227///
228/// The concrete type must implement both [`Rustlet`] and
229/// [`RustletSecurityDomain`]. It remains a normal selectable Rustlet through
230/// `process_apdu`, while the kernel can also call the generated Security
231/// Domain vtable through a proxy.
232///
233/// Accepts the same heap and installer forms as [`declare_rustlet!`], with the
234/// same `Default` and serde requirements. Adds persistent administrative metadata
235/// to the serialized application state, reducing its available state capacity.
236/// Secure-channel session fields should be skipped by serde and cleared by
237/// `reset_secure_channel`. The active SD object can remain resident between
238/// calls; its administrative role does not confer CPU privilege. The kernel's
239/// proxy remains responsible for ownership and privilege checks.
240macro_rules! declare_security_domain {
241    // Default overload: use implicit install with a default heap size (768 bytes).
242    ($app_ty:ty) => {
243        $crate::declare_security_domain!(@implicit $app_ty, 768usize);
244    };
245
246    // Custom heap size overload with implicit install.
247    ($app_ty:ty, $heap_size:expr) => {
248        $crate::declare_security_domain!(@implicit $app_ty, $heap_size);
249    };
250
251    // Fully explicit overload: custom heap size and custom install function.
252    ($app_ty:ty, $heap_size:expr, $install_fn:path) => {
253        $crate::declare_security_domain!(@explicit $app_ty, $heap_size, $install_fn);
254    };
255
256    (@implicit $app_ty:ty, $heap_size:expr) => {
257        #[doc(hidden)]
258        fn __oxide_se_implicit_install(ctx: &mut $crate::RustletCtx) -> core::result::Result<$app_ty, $crate::ApduStatus> {
259            <$app_ty as $crate::rt::DeclareAppWithoutInstallRequiresDefault>::implicit_install(
260                ctx,
261            )
262        }
263
264        $crate::declare_security_domain!(@explicit $app_ty, $heap_size, __oxide_se_implicit_install);
265    };
266
267    (@explicit $app_ty:ty, $heap_size:expr, $install_fn:path) => {
268        extern crate alloc;
269
270        #[doc(hidden)]
271        static __OXIDE_SE_RUSTLET_HEAP_STORAGE: $crate::rt::RustletHeapStorage<{ $heap_size }> =
272            $crate::rt::RustletHeapStorage::new();
273
274        #[doc(hidden)]
275        fn __oxide_se_install_adapter(
276            ctx: &mut $crate::RustletCtx,
277        ) -> core::result::Result<$crate::rt::RuntimeInstance, $crate::ApduStatus> {
278            fn __oxide_se_assert_security_domain<T: $crate::RustletSecurityDomain>() {}
279            __oxide_se_assert_security_domain::<$app_ty>();
280            let instance: $app_ty = $install_fn(ctx)?;
281            let mut instance = $crate::rt::PersistentSecurityDomain::new(instance);
282            instance.initialize_from_install_apdu(ctx)?;
283            Ok($crate::rt::RuntimeInstance::SecurityDomain(
284                alloc::boxed::Box::new(instance),
285            ))
286        }
287
288        #[doc(hidden)]
289        fn __oxide_se_load_adapter(
290            _ctx: &mut $crate::RustletCtx,
291        ) -> core::result::Result<$crate::rt::RuntimeInstance, $crate::ApduStatus>
292        where
293            $app_ty: core::default::Default,
294        {
295            fn __oxide_se_assert_security_domain<T: $crate::RustletSecurityDomain>() {}
296            __oxide_se_assert_security_domain::<$app_ty>();
297            let instance = <$app_ty as core::default::Default>::default();
298            Ok($crate::rt::RuntimeInstance::SecurityDomain(
299                alloc::boxed::Box::new($crate::rt::PersistentSecurityDomain::new(instance)),
300            ))
301        }
302
303        #[unsafe(no_mangle)]
304        #[doc(hidden)]
305        /// # Safety
306        /// Called once by the kernel with this image's GP and exclusive memory
307        /// established; no previous runtime instance or handler may be active.
308        pub unsafe extern "C" fn start(buffer: *mut $crate::RustletCtx) -> ! {
309            // SAFETY: the kernel entry contract and private static heap establish
310            // the runtime startup obligations for this relocated image.
311            unsafe {
312                $crate::rt::start_security_domain(
313                    __oxide_se_install_adapter,
314                    __oxide_se_load_adapter,
315                    buffer,
316                    __OXIDE_SE_RUSTLET_HEAP_STORAGE.as_mut_ptr(),
317                    $heap_size,
318                )
319            }
320        }
321    };
