pub fn from_install_bytes( bytes: &[u8], ) -> Result<Self, SecurityDomainPrivilegeError>

Decodes the raw GlobalPlatform privilege bytes carried by INSTALL.

Accepts zero through three bytes, copying them into inline storage with zero padding. More than three returns TooLong. Queries interpret the first byte and selected second-byte bits; other bits are preserved. Decoding is not an authorization decision.
