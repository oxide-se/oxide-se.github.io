Expand description

Trait implemented by a Rustlet application.

A Rustlet is responsible for processing APDUs and optionally loading and saving its persistent state.

With crate::declare_rustlet!, the generated PersistentRustlet wrapper supplies postcard persistence rather than delegating to this type’s custom load/save overrides. Implement serde on the application state in that path.

Required Methods§

Source

fn process_apdu(&mut self, ctx: &mut RustletCtx) -> ApduStatus

Handle an incoming APDU using the provided runtime context. The context and its payload are exclusive loans for this invocation. Return the status after staging any response. Do not retain references into the context or expect transient ordinary-instance fields to survive the runtime’s serialization/drop/reconstruction boundary.

Provided Methods§

Source

fn load_state(&mut self, state: &[u8]) -> Result<(), ApduStatus>

Load state from the provided byte slice.

The default implementation accepts an empty state and returns wrong_data for any non-empty input.

Source

fn save_state(&self, _out: &mut [u8]) -> Result<usize, ApduStatus>

Save state into the provided output buffer.

The default implementation does nothing and returns a length of 0.
