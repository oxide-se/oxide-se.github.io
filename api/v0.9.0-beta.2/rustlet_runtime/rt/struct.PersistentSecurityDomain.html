Struct PersistentSecurityDomain 

Source 
pub struct PersistentSecurityDomain<T> { /* private fields */ }
Expand description

Postcard adapter adding a six-byte administrative header to SD state. The header stores encoding version, lifecycle and privilege bytes; the remaining state capacity belongs to T. Active nonserialized session state can remain resident. The wrapper supplies administrative queries itself and delegates protocol hooks to the inner SD.

pub fn initialize_from_install_apdu( &mut self, ctx: &mut RustletCtx, ) -> Result<(), ApduStatus>

Read the privilege LV from the staged installation envelope. Empty input resets to empty administrative state. Malformed leading LVs or more than three privilege bytes return 6A80. This only initializes runtime metadata; it does not validate the full envelope or grant authority.
