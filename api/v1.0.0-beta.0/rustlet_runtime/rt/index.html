Entry, allocation and persistent lifecycle glue enabled by runtime.

Application authors implement Rustlet and use the declaration macros. Startup and wrapper types here support those macros across crate boundaries; constructing them manually is not a substitute for validated kernel entry. The allocator and panic handler require an active embedded invocation. Ordinary applications are reconstructed and serialized per call; Security Domains can retain volatile channel state while active.

Structs§

PersistentRustlet
Runtime adapter that delegates APDUs to T and persists it through postcard. Requires serde via the internal PostcardState bound. Empty saved state leaves the reconstructed default object unchanged; nonempty state replaces it by deserialization. Encoding overflow maps to 6700, invalid input to 6A80. The wrapper does not call T’s custom trait load/save hooks.
PersistentSecurityDomain
Postcard adapter adding a six-byte administrative header to SD state. The header stores encoding version, lifecycle and privilege bytes; the remaining state capacity belongs to T. Active nonserialized session state can remain resident. The wrapper supplies administrative queries itself and delegates protocol hooks to the inner SD.
