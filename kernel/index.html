Start at the boundaries.

  2. Explore the core.kernel/core provides reusable embedded services through oxi_core.
  3. Trace firmware and applications.kernel/firmware owns the production APDU loop; rustlets/rustlet_runtime defines the application ABI and runtime.
  4. Follow orchestration.xtask drives builds, packaging, QEMU/OpenOCD execution and integration scenarios.

Verification

Know what each check proves.

cargo fmt --all -- --check
cargo clippy --workspace --all-targets --offline -- -D warnings
cargo test --offline

Formatting and Clippy enforce source and lint policy. Host tests cover Rust test harnesses and the workspace’s configured test behavior; QEMU integration campaigns add target execution and APDU paths. Hardware campaigns additionally exercise real flash, reset, UART and board behavior. A passing host suite is not a hardware-validation claim.

Begin with the native ELF path.Kernel FAE images are deprecated. Rustlet FAE payloads remain supported; the kernel itself is built as a native fixed-address ELF.

Contribution areas

Pick one observable improvement.

  • Clarify a guide or make a documented command reproducible.
  • Add a regression scenario around an APDU, persistence or isolation edge.
  • Reduce copies or stack pressure within a measured path.
  • Narrow and document an unsafe boundary.
  • Bring up or strengthen a Cortex-M board port.
  • Correct a GlobalPlatform behavior and demonstrate it with a focused test.

Open an Issue to describe a problem or proposal, then follow the repository’s existing contribution guidance. The public branch is a release-snapshot showcase; site commits and private development history do not belong in it.
