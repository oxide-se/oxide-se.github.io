Integrity

Check the download.

Download SHA256SUMS →

Keep the checksum file beside the four downloaded images. With all four files present, run:

sha256sum -c SHA256SUMS        # Linux
shasum -a 256 -c SHA256SUMS  # macOS

If you download only one image, compare its SHA-256 with the value shown above; the full checksum command reports missing files when the other images are absent.

Before installing

Use a development board.

Full-flash erase.Each UF2 resets the board's entire declared flash, including previously loaded applications and persistent data. The documented OpenOCD installation path also erases the flash. Back up anything you need first.

USB BOOTSEL installs the firmware; runtime APDUs use UART0 on GPIO0/GPIO1 at 115200 baud. Open the UART client before boot if you need to capture the one-time ATR.

This bundle passed a Pico 1 QEMU tutorial run and a physical Pico 2 OpenOCD tutorial run. Physical Pico 1 installation and USB BOOTSEL transfer were not exercised for this bundle. The UF2 payloads were verified against the corresponding full-flash ELF images.

Explore the Devkit path. Its existing build walkthrough is pinned to v1.0.0-beta.0; the matching tutorial for these dated images will accompany the next source release.
