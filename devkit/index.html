Fast track: Run a Rustlet in 15 minutes.

Start an emulated Pico 1 and get your first CA FE response. Allow about 15 minutes if Git, Rust and the ARM tools are already installed. See the host tool setup if you need them.

1. Get QEMU and the DevKit

The commands below download QEMU RFC v4 for Linux x86-64 or Apple Silicon and the Pico 1 DevKit ELF. They clone the matching source tag into ~/oxide-se-fast-track and build the APDU client.

(
  set -e
  case "$(uname -s):$(uname -m)" in
    Linux:x86_64) qemu=qemu-pico1-rfc-v4-linux-amd64 ;;
    Darwin:arm64) qemu=qemu-pico1-rfc-v4-macos-arm64 ;;
    *) echo "Use Linux x86-64 or Apple Silicon." >&2; exit 1 ;;
  esac

  git clone --depth 1 --branch v1.0.0-beta.2 \
    https://github.com/oxide-se/oxide-se.git "$HOME/oxide-se-fast-track"
  cd "$HOME/oxide-se-fast-track"
  mkdir -p target/fast-track
  curl -fL "https://github.com/2xs/qemu-rp2040-pico/releases/download/rp2040-pico-rfc-v4/$qemu.tar.gz" \
    -o target/fast-track/qemu.tar.gz
  tar -xzf target/fast-track/qemu.tar.gz -C target/fast-track
  ln -s "$qemu/qemu-system-arm" target/fast-track/qemu-system-arm
  curl -fL https://oxide-se.github.io/downloads/devkit-2026.11.27/oxide-se-devkit-pico1.elf \
    -o target/fast-track/devkit.elf
  git submodule update --init tooling/build-fae
  cargo build -p apdu_tool
)

2. Build the CA FE Rustlet

Paste this block to put the demo into the template in your new checkout and build the Pico 1 FAE.

(
  set -e
  cd "$HOME/oxide-se-fast-track"
  cd rustlets/rustlet_template
  cat > src/main.rs <<'RUST'
#![no_std]
#![no_main]

use rustlet_runtime::{declare_rustlet, Apdu, ApduStatus, Rustlet, RustletCtx, State};

declare_rustlet!(CafeRustlet, 256);

struct CafeRustlet;

impl Rustlet for CafeRustlet {
    type Persistent = ();
    type Session = ();

    fn process_apdu(_state: &mut State<(), ()>, ctx: &mut RustletCtx) -> ApduStatus {
        let apdu = Apdu::new(ctx);
        match apdu.ins() {
            0x04 => apdu.as_sending().send(&[0xCA, 0xFE]),
            _ => apdu.reject(ApduStatus::instruction_not_supported()),
        }
    }
}
RUST
  RUSTLET_TARGET=thumbv6m-none-eabi cargo build-fae
)

3. Start QEMU and read the ATR

Run QEMU in the first terminal and leave it running. It waits for the APDU client before booting the firmware.

cd "$HOME/oxide-se-fast-track" &&
  target/fast-track/qemu-system-arm -machine raspi-pico \
    -display none -monitor none \
    -serial tcp:127.0.0.1:4444,server=on,wait=on \
    -semihosting-config enable=on,target=native \
    -kernel target/fast-track/devkit.elf

Open a second terminal and run:

cd "$HOME/oxide-se-fast-track"
target/debug/apdu_tool --serial 127.0.0.1:4444 atr

4. Deploy it and send an APDU

After the ATR appears, paste this into the second terminal. The deployment command loads and installs the Rustlet.

target/debug/apdu_tool --progress gp deploy \
  A0000047504F5321 rustlets/rustlet_template/build/rustlet_template.fae \
  A0000047504F5322 --security-domain A0000047504F5301 &&
target/debug/apdu_tool select A0000047504F5322 &&
target/debug/apdu_tool raw 00:04:00:00:00:02

The last command returns CA FE and status 90 00.

target/debug/apdu_tool close

Press Ctrl+C in the QEMU terminal to stop the emulator.

Before you begin

Quick start on a physical Pico.

Looking for the complete walkthrough?The Getting Started covers prerequisites, firmware builds, OpenOCD, Pico 1 emulation and troubleshooting. The shorter path below uses a ready-built UF2 on a physical Pico 1 or Pico 2.

You need a development Pico, a USB data cable and a 3.3 V UART bridge connected to GPIO0 (Pico TX), GPIO1 (Pico RX) and ground. The UART runs at 115200 baud, 8N1, without flow control.

Download and prepare

Get the image and the tools.

  1. Download the UF2 for your board.Use the Pico 1 image or the Pico 2 image. Checksums and ELF variants are available on the Downloads page.
  2. Clone the matching release.The source, Rustlet ABI and ready-built images are all pinned to v1.0.0-beta.2.
  3. Build the host client.Initialize the FAE build helper, then compile apdu_tool.
git clone --branch v1.0.0-beta.2 \
  https://github.com/oxide-se/oxide-se.git
cd oxide-se
git submodule update --init tooling/build-fae
cargo build -p apdu_tool

If a required host tool is missing, stop here and follow the host tool setup instructions.

Install and boot

Start the devkit and read its ATR.

The UF2 erases the complete flash.It removes previously installed Rustlets and persistent data. Use a development board whose contents may be replaced.
  1. Install the image.Hold BOOTSEL while connecting the Pico over USB, release it, then copy the matching UF2 to the mounted drive. It is named RPI-RP2 on Pico 1 and RP2350 on Pico 2.
  2. Wait for the ATR.With the UART bridge connected, start the command below from the repository root. Replace the serial device with yours.
  3. Reset the Pico.Press Reset after apdu_tool is waiting. The ATR is emitted only once at boot.
target/debug/apdu_tool -v \
  --serial /dev/ttyACM0:115200 \
  --connect-timeout 120s \
  --atr-timeout infinite atr

On macOS, use the matching /dev/cu.usbmodem... device. On Windows, use a value such as COM3:115200. The expected ATR is:

3B 1C 11 80 56 09 C1 DE 5E 10 00 73 80 00 00

The successful command creates session.json. Keep running the following commands from the repository root so they reuse that connection.

Build and load

Make the template answer CA FE.

In rustlets/rustlet_template/src/main.rs, replace the existing match apdu.ins() expression with:

match apdu.ins() {
    0x04 => apdu.as_sending().send(&[0xCA, 0xFE]),
    _ => apdu.reject(ApduStatus::instruction_not_supported()),
}

Build the FAE for your board:

cd rustlets/rustlet_template

# Pico 1:
RUSTLET_TARGET=thumbv6m-none-eabi cargo build-fae

# Pico 2: use this command instead:
# RUSTLET_TARGET=thumbv8m.main-none-eabihf cargo build-fae

cd ../..

Deploy the package, select its instance, then send instruction 04:

target/debug/apdu_tool --progress gp deploy \
  A0000047504F5321 \
  rustlets/rustlet_template/build/rustlet_template.fae \
  A0000047504F5322 --security-domain A0000047504F5301

target/debug/apdu_tool select A0000047504F5322
target/debug/apdu_tool raw 00:04:00:00:00:02

The final command must return CA FE and status 90 00. Close the local client session when finished:

target/debug/apdu_tool close

This removes session.json; it does not uninstall the Rustlet from the Pico.

A development configuration.The devkit uses a permissive root and no Secure Channel. Anyone with access to the APDU link may request deployment. It is for prototyping, not production security policy.
